Single-package Flutter application rooted at `lib/main.dart`, which bootstraps a `MaterialApp` wrapped in a `ThemeProviderScope`/`ListenableBuilder` for light/dark mode persistence. The Dart source is organized into six top-level folders: `screens/` (feature UI pages — splash, onboarding, login, signup, forgot password, home, profile settings), `services/auth_service.dart` (stateless HTTP client wrapping `package:http` against endpoints in `config/api_config.dart`, persisting JWT and cached user data via `flutter_secure_storage`), `models/user.dart` (immutable JSON-serializable domain object), `theme/app_theme.dart` + `theme/theme_provider.dart` (centralized Material 3 theme with olive-green accent and PlusJakartaSans typography plus a `ChangeNotifier`-based theme state provider), and `widgets/` (reusable `AuthTextField` and `ThemeToggle`). Platform-specific native code lives in the standard Flutter scaffolding under `android/`, `ios/`, `linux/`, `macos/`, `web/`, `windows/`; these contain only generated plugin registrants, launch assets, and CMake/Xcode project files — no custom platform channels are implemented here. Dependency direction is strictly one-way: screens → services → models/config; themes/widgets are leaf utilities consumed by screens.
