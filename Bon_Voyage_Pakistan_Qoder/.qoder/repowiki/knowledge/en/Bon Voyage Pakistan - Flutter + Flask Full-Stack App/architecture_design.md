The repository is a flat full-stack project: the root `pubspec.yaml` declares the Flutter app (client) dependencies, while sibling directories hold the `flutter_app` (Flutter multi-platform UI) and `backend_api` (Flask REST API with SQLite). The two children communicate over HTTP — the Flutter app calls the Flask endpoints for signup, login, profile access, and logout, exchanging JWTs stored via `flutter_secure_storage`. There is no shared code or build script at this level; each child is developed and run independently from its own directory.
