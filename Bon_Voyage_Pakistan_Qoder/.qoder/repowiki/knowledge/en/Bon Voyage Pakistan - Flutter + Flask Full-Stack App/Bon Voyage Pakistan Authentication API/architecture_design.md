Two-file monolith: `app.py` defines the Flask application, CORS middleware, JWT decode/encode helpers, a `@token_required` decorator that extracts Bearer tokens from the Authorization header and injects the resolved user into protected routes, and all `/auth/*` endpoints; `database.py` encapsulates SQLite connectivity via a shared `get_connection()` factory with `sqlite3.Row` row factories and exposes CRUD functions (`init_db`, `create_user`, `find_user_by_email`, `find_user_by_id`) against a single `users` table. Dependency direction is one-way: `app.py` imports from `database.py`; configuration (SECRET_KEY, JWT_EXPIRATION_HOURS) is loaded from `.env` via `python-dotenv`. A standalone `test_api.py` script exercises the running server over HTTP using `requests`.
